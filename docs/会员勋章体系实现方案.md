## 一、原始效果机制解析（依据官方源码）

v3 依据 21st.dev 提供的原始 React 源码逐行移植，其真实机制如下（**与前两版近似实现有本质区别**）：

| 层次 | 原始实现 |
|---|---|
| 外形 | SVG 胶囊，`viewBox="0 0 260 54"`，`rx=10` 圆角 |
| 底色 | 纯色粉彩，按 `place` 取 `["#f3e3ac", "#ddd", "#f1cfa6"]` |
| 内描边 | `rect x=4 y=4 252×46 rx=8`，`stroke #bbb` |
| 图标 | 月桂花环 path（`translate(8,9)`），纯色 `#666` |
| 文字 | 眉题 9px / 标题 16px，Helvetica-Bold，`#666` |
| **全息彩虹层** | **10 条 `blur(3)` 的对角线多边形**（`points="0,0 260,54 260,0 0,54"`），置于 `<g style="mix-blend-mode: overlay">` 内并以 `mask` 裁切到胶囊圆角；颜色为 `hsl(358/30/60/96/233/271/300 …)` + 透明 + 白；**每层基准角按 10° 步进递增** |
| **静止动画** | 每层挂 `overlayAnimationN 5s infinite`，在 `N*10°` 与 `(N+1)*10°` 之间往复 → **彩虹持续「呼吸」摆动** |
| **指针联动** | `firstOverlayPosition = (|Δx| + |Δy|) / 1.5`（指针到徽章中心的曼哈顿距离），**驱动整组彩虹共同旋转**；指针移动后延迟 150ms 跟随 → 液体滞后感 |
| **3D 变换** | `perspective(700px) matrix3d(...)`：距离衰减缩放（`0.97 → 1.0`）+ 多轴旋转（`±0.25`），随指针实时更新 |
| **弹簧编排** | 进入：先施加 `0.7` 衰减的**反向矩阵**，200ms 后切换为实时跟随；离开：施加 `1/4` 衰减反向矩阵，200ms 后回单位阵；彩虹则按 150ms → `-pos/4`、300ms → `0`、500ms → 恢复静止摆动 级联回弹 |

**关键结论：原效果的核心不是「一条渐变光带横向平移」，而是「一组模糊对角多边形在 overlay 混合下的旋转呼吸 + 指针距离驱动」，且静止时也一直在动。**

## 二、分级多元化勋章体系

### 2.1 等级维度（与后端 `t_member_level` 一一映射）

| levelId | 等级 | tier | 徽记 | 底色 | 徽记渐变 |
|---|---|---|---|---|---|
| 1 | 普通会员 | `regular` | 月桂 | `#e7ebef` | `#A8BCCD → #6F8BA3` |
| 2 | 白银会员 | `silver` | 盾星 | `#dddddd`（沿用源码 place2） | `#C3CCD6 → #8C99A8` |
| 3 | 黄金会员 | `gold` | 皇冠 | `#f3e3ac`（沿用源码 place1） | `#F2D489 → #B98A3C` |
| 4 | 钻石会员 | `diamond` | 宝石 | `#d7e6f7` | `#BFE0FF → #5F9ADA` |

### 2.2 成就维度（前端按会员数据派生，无后端改动）

| 勋章 | tier | 维度眉题 | 解锁条件 |
|---|---|---|---|
| 初出茅庐 | `azure` | GROWTH · 成长 | 成长值 ≥ 100 |
| 积分达人 | `regular` | POINTS · 积分 | 积分 ≥ 1000 |
| 成长先锋 | `gold` | MILESTONE · 里程碑 | 成长值 ≥ 5000 |
| 至尊挚友 | `diamond` | LOYALTY · 忠诚 | 成长值 ≥ 20000 |

新增配色只需在组件 `<style>` 内追加一个 `.mb-badge.mb-<tier>` 令牌块（底色 + 两个徽记渐变端点）。

### 2.3 状态模型

| state | 语义 | 视觉 |
|---|---|---|
| `locked` | 未解锁 | `grayscale(.92)` + `opacity .55`，彩虹层停止摆动，🔒 角标 |
| `earned` | 已获得 | 全彩，彩虹持续摆动，入场弹跳 + 一次旋绕 |
| `current` | 当前等级 | 全彩 + 「当前」角标 + 3.2s 等级色辉光脉冲 |

## 三、标准图片模板规范

### 3.1 矢量母版（Source of Truth）

位置：`frontend/public/badges/templates/`，**规格 260×54**（与组件同构）

| 文件 | 用途 |
|---|---|
| `mb-level-regular.svg` | 普通会员（月桂） |
| `mb-level-silver.svg` | 白银会员（盾星） |
| `mb-level-gold.svg` | 黄金会员（皇冠） |
| `mb-level-diamond.svg` | 钻石会员（宝石） |
| `mb-ach-star.svg` | 成就维度通用（星芒） |

母版层级（自下而上）：等级底色 → 内描边 → 眉题/标题 → 等级徽记 → **全息彩虹组（8 层，overlay 混合 + 圆角 mask + blur(3)）**。

> 母版内嵌 `<style>` 关键帧，**直接用浏览器打开即可看到彩虹摆动动画**；同时不影响作为静态切图源使用。

### 3.2 导出尺寸刻度

| 导出宽 | viewBox 缩放 | 场景 |
|---|---|---|
| 112px | 0.43× | 列表 / 消息内联 |
| 190px | 0.73× | 勋章墙（组件 `size="sm"`） |
| 300px | 1.15× | 勋章墙默认（组件 `size="md"`） |
| 364px | 1.40× | 详情弹窗（组件 `size="lg"`） |
| 520px | 2× | 分享卡片 / 高清导出 |

矢量为母版，任意尺寸无损；栅格导出建议 1x/2x/4x PNG，命名 `mb-<tier>-<width>@<scale>.png`。

### 3.3 状态渲染规则（栅格导出时）

- `locked`：`filter: grayscale(92%)` + `opacity: 55%`，彩虹层不参与
- `earned`：原样导出（彩虹层取任意一帧即可）
- `current`：叠加 `box-shadow: 0 0 18px 3px <等级色辉光>`

## 四、动效规范（v3 · 源码逐行移植）

| 动效 | 触发 | 参数（与源码一致） | 属性 |
|---|---|---|---|
| 彩虹静止摆动 | 常驻（earned/current） | 每层 `5s infinite`，`N*10° ↔ (N+1)*10°` | transform |
| 彩虹指针驱动 | `pointermove` | `(|Δx|+|Δy|)/1.5`，延迟 150ms 跟随 | transform |
| 3D 跟随 | `pointermove` | `perspective(700px) matrix3d(...)`，缩放 0.97–1.0，旋转 ±0.25，`200ms ease-out` | transform |
| 进入弹簧 | `pointerenter` | 反向矩阵（0.7 衰减）→ 200ms 后实时跟随；彩虹过渡开关 350ms 后关闭 | transform |
| 离开弹簧 | `pointerleave` | 反向矩阵（1/4 衰减）→ 200ms 回单位阵；彩虹 150ms `-pos/4` → 300ms `0` → 500ms 恢复摆动 | transform |
| 获取/升级旋绕 | `burst` 挂载单次 | 彩虹从 `-150°` 缓出至 `0°`，900ms | transform |
| 解锁入场 | earned/current 挂载 | `0.55s` spring，列表错峰 `delay = i*90ms` | transform + opacity |
| 当前等级辉光 | current 循环 | `3.2s ease-in-out` | box-shadow |

**动画节奏的场景化区分**：
- **展示（默认）**：仅彩虹 5s 呼吸 —— 低干扰、持续「活着」
- **升级/获取（`burst=true`）**：额外 900ms 旋绕 + 入场弹跳 —— 一次性强化反馈
- **交互（hover）**：彩虹滞后跟随 + 3D 倾斜 + 进出场弹簧

### 4.1 点击交互：勋章详情弹窗

徽章 `role=button`、`tabindex=0`，支持 Enter / Space 激活，触发 `detail` 事件；会员中心弹出 `a-modal` 详情卡：大号徽章（`size="lg"`）+ 状态 / 解锁条件 / 当前进度（`a-progress`）/ 勋章说明。

## 五、组件 API 与集成

```vue
<MembershipBadge
  tier="gold"                <!-- regular | silver | gold | diamond | azure -->
  eyebrow="LEVEL 3"          <!-- 眉题（SVG 内 9px 字号） -->
  title="黄金会员"            <!-- 主标题（SVG 内 16px 字号，整体随宽度等比缩放） -->
  state="current"            <!-- locked | earned | current -->
  size="md"                  <!-- sm(190) | md(300) | lg(360) -->
  :delay="180"               <!-- 入场错峰延迟 ms -->
  :burst="true"              <!-- 获取/升级：挂载时彩虹旋绕一次 -->
  link="/membership/levels"  <!-- 可选：点击跳转（不传则 emit detail） -->
  @detail="openDetail(m)"    <!-- 点击详情 -->
/>
```

深色模式：组件内 `[data-theme='dark']` 覆盖底色与徽记渐变为暗色金属系、文字反白，彩虹层维持 overlay 混合，无需额外配置。

## 六、多端一致性与性能取舍

**响应式**：徽章宽度按容器自适应，`max-width` 由 `size` 决定；`viewBox` 等比缩放保证文字与图形在各尺寸完全一致（矢量，无位图失真）。勋章墙 `auto-fill minmax(280px,1fr)` → ≤620px 单列。

**性能优化（相对源码的取舍）**：
1. **彩虹层由 10 层精简为 8 层** —— 原源码第 8、9 层为 `transparent` 填充，渲染无贡献却仍参与 `blur` 光栅化；去掉后可省约 20% 滤镜开销，视觉完全等价。
2. **未解锁徽章不参与动画** —— `locked` 态直接 `animation: none`，勋章墙中未解锁项零动画成本。
3. **交替控制动画与内联 transform** —— 静止时由 CSS 关键帧驱动、指针交互时切换为内联 `transform`（与源码同机制），避免同一元素上动画与内联值互相覆盖。
4. **`contain: layout paint`** 于徽章容器，隔离重绘范围。
5. **`will-change: transform`** 仅施加于 3D 容器（每个徽章 1 处），不下放到 8 条彩虹带，避免每条带都提升为独立合成层导致显存膨胀。
6. **指针事件使用 `rAF`/`setTimeout` 节流**，并复用源码的 150ms 延迟跟随节奏。
7. **`prefers-reduced-motion: reduce`**：彩虹摆动、入场弹跳全部关闭，3D 与弹簧交互直接短路（JS 层 `matchMedia` 判断），渲染为静态徽章。
8. **触屏设备**（`pointerType === 'touch'`）：跳过 3D 与指针跟随逻辑，保留彩虹呼吸作为主要动效，避免无意义的计算。

**实测**：`npm run build` 通过；勋章墙 8 枚徽章（约 3 枚带动画）在中端设备滚动流畅，无长任务告警。
