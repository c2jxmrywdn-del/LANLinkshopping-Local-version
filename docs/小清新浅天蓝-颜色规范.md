# 小清新浅天蓝 · 全局交互颜色规范

> 适用范围：LANLinkshopping 前端全站（含 MainLayout 前台、AdminLayout 后台）
> 关联实现：[`frontend/src/styles/theme.css`](../frontend/src/styles/theme.css)（CSS 变量，唯一改色入口）
> 对比度实测：[小清新浅天蓝-对比度测试报告](./小清新浅天蓝-对比度测试报告.md)

## 1. 设计目标

- 全部可交互元素（按钮、链接、图标按钮、下拉选项、卡片点击区）点击反馈统一为**小清新浅天蓝**。
- "加入购物车"按钮在**列表页 / 详情页 / 购物车页**等所有出现位置使用同一套四态颜色。
- 颜色满足：柔和不刺眼、明亮通透、饱和度 30–45%（浅底填充色）。
- 全站通过 CSS 变量 + antd Theme Token 双通道管理，改色只动一处。
- 满足 WCAG 2.1 AA：普通文本 ≥4.5:1、大文本 ≥3:1、非文本 UI 组件 ≥3:1。

## 2. 候选色值（供视觉确认，均可一键切换）

三个候选均为浅天蓝系，色相 198°–204°，饱和度 35%–45%，亮度 73%–78%。
当前用于**全局点击态填充**（普通按钮/菜单/下拉/卡片按压），"加入购物车"按钮另行使用品牌渐变（见 §4）。

| 候选 | 色值 | RGB | HSL | 说明 |
| --- | --- | --- | --- | --- |
| **A（已应用）** | `#A9CADA` | `RGB(169, 202, 218)` | `HSL(200°, 40%, 76%)` | 平衡之选，亮度适中，作为点击态填充主色 |
| B | `#B3CFDA` | `RGB(179, 207, 218)` | `HSL(198°, 35%, 78%)` | 更通透轻盈，适合偏浅的视觉偏好 |
| C | `#9BC0D9` | `RGB(155, 192, 217)` | `HSL(204°, 45%, 73%)` | 略深一档，层次感更强，兼作按压填充 |

**切换方式**：改 `theme.css` 中 `--ll-skyblue` 一个变量即可；悬停/按压/边框由程序化微调联动。

## 3. 色板 Token（唯一事实源）

| Token | 用途 | 色值 |
| --- | --- | --- |
| `--ll-brand-gradient` | "加入购物车"按钮默认底（天蓝→青渐变） | `linear-gradient(92deg, #38BDF8, #22D3EE)` |
| `--ll-skyblue` | 全局点击态填充主色 | `#A9CADA` |
| `--ll-skyblue-hover` | 点击态悬停（提亮约 4pp） | `#B7D4E2` |
| `--ll-skyblue-active` | 点击态按压（略深，反馈点击） | `#9BC0D9` |
| `--ll-skyblue-border` | 协调边框（白底非文本 ≥3:1） | `#5B8FB5` |
| `--ll-skyblue-on` | 浅天蓝底上的文字（AA ≥4.5:1） | `#1F3864` |
| `--ll-skyblue-disabled` | 点击态禁用底（45% 透明度） | `rgba(169,202,218,.45)` |
| `--ll-skyblue-on-disabled` | 禁用文字（50% 透明度） | `rgba(31,56,100,.5)` |
| `--ll-primary` | antd 主按钮色（白字 AA） | `#1E6EB8` |
| `--ll-primary-hover` | 主按钮悬停（白字 AA） | `#2774BD` |
| `--ll-primary-active` | 主按钮按压（白字 AA） | `#155B9E` |
| `--ll-transition-base` | 状态切换过渡时长 | `0.25s` |
| `--ll-transition-fast` | 快捷过渡（如透明度） | `0.2s` |

## 4. 状态定义

### 4.1 "加入购物车"按钮（品牌渐变，与全站品牌色同源）

| 状态 | 背景 | 边框 | 文字 | 说明 |
| --- | --- | --- | --- | --- |
| 默认 | `--ll-brand-gradient`（天蓝 `#38BDF8`→青 `#22D3EE`） | 透明 | `--ll-navy` | 与 LOGO/首页装饰同一组 token |
| 悬停 | 同上 + `brightness(1.05)` | 透明 | `--ll-navy` | 提亮，0.25s 平滑过渡 |
| 点击 | 同上 + `brightness(0.94)` | 透明 | `--ll-navy` | 略压暗，反馈点击 |
| 禁用 | 同上 + `opacity: 0.45` | 透明 | 降透明 | 灰化不可点 |

### 4.2 全局点击态（普通按钮/链接/卡片/菜单/下拉）

| 状态 | 背景 | 边框 | 文字 | 说明 |
| --- | --- | --- | --- | --- |
| 默认 | 随元素类型（antd 默认白底等） | `--ll-skyblue-border` | 原有文字色 | — |
| 悬停 | `--ll-skyblue-hover`（卡片投影淡入） | `--ll-skyblue-border` | 原有文字色 | 0.2–0.25s |
| 点击 | `--ll-skyblue-active` | `--ll-skyblue-border` | `--ll-skyblue-on` | 全局统一浅天蓝 |
| 禁用 | `--ll-skyblue-disabled` | 透明 | `--ll-skyblue-on-disabled` | 透明度 45%/50% 灰化，不可点 |

### 4.3 主按钮（白字，如"立即购买/去结算/提交订单/登录"）

沿用 antd 天蓝主色（`--ll-primary` 默认 / `--ll-primary-hover` 悬停 / `--ll-primary-active` 按压），保证白字对比度。

## 5. 全局点击状态覆盖范围

| 元素 | 规则 | 位置 |
| --- | --- | --- |
| "加入购物车"按钮 | 品牌渐变底 + 深海军蓝文字，四态见 §4.1 | `theme.css` 全局 `.ll-add-cart` |
| 链接 `<a>` | `a:active` 文字变浅天蓝 | `theme.css` 全局 |
| 默认/描边/幽灵按钮 | `:active` 填充浅天蓝 + 协调边框 | `theme.css` 全局 |
| 可点击卡片 `.ant-card-hoverable` | `:active` 描边 + 浅天蓝投影 | `theme.css` 全局 |
| 菜单项/下拉/下拉选项 | `:active` 填充浅天蓝 | `theme.css` 全局 |
| 主按钮（白字） | antd token 按压加深（天蓝系） | `App.vue` Theme Token |
| 下拉选中/菜单选中/Tab 激活/焦点描边 | antd 由 `colorPrimary` 派生浅天蓝系 | `App.vue` Theme Token |

## 6. 响应式与跨设备一致性

- 颜色全部由 CSS 变量/Theme Token 声明，**与视口尺寸无关**，桌面/平板/移动端渲染一致。
- 同一类型元素（按钮、菜单、卡片）在首页、分类页（Mall）、详情页、结算页均引用同一 token，杜绝页面级硬编码色值差异。
- 深浅色主题：`App.vue` 中 antd `darkAlgorithm` 保留，浅天蓝系为品牌色，暗色模式下仍由 token 派生，保持可读性。

## 8. 可访问性

- 全部关键文字/背景组合实测对比度见对比度测试报告，普通文本全部 ≥4.5:1。
- 品牌渐变底上白字（约 1.8–2.3:1）**故意规避**——"加入购物车"按钮改用深海军蓝文字（渐变两端实测 5.42:1 / 6.43:1）。
- 状态区分不单靠颜色：悬停有光标/描边、点击有位移反馈、禁用灰化且不可点，色盲用户可区分。
- 禁用态按 WCAG 1.4.3 豁免对比度要求。
