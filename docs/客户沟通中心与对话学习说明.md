# LANLinkshopping 客户沟通中心与对话学习

## 目的与范围

客户沟通中心是网站专属客服的运营工作台，复用现有 Vue 3 / Ant Design Vue 管理后台与 Spring Boot API。管理接口受后端 /admin/** 平台运营角色校验保护；所有写操作统一经过 CSRF 防护。前端路由守卫只做第一层体验保护，不能替代后端鉴权。

## 主流程与层级

- 一级：/admin/communications — 沟通概览、会话量与待处理/未分配/待审核计数。
- 二级：/admin/communications/inbox — 队列、状态、优先级和会话查询。
- 三级：/admin/communications/conversations/:conversationId — 消息时间线、回复、内部备注、认领/取消认领、状态/优先级及候选知识创建。
- 四级：/admin/communications/conversations/:conversationId/messages/:messageId — 单条消息只读详情及会话上下文。
- 学习流程三级：/admin/communications/learning — 待审核、已发布、已驳回候选列表。
- 学习流程三级：/admin/communications/learning/:candidateId — 候选内容、来源问答和审核历史。
- 学习流程四级：/admin/communications/learning/:candidateId/review — 事实、隐私、范围/重复意图核验后再发布或驳回。
- /admin/support-learning 保留为管理端入口；候选评估已改由独立 Docker 容器执行，生产知识匹配结果与重复意图判断仍由受控的 Spring Boot 服务提供。

## 对话记录

网页客服对话通过 Vercel 同源代理发送。浏览器为访客生成随机会话 UUID，使用 sessionStorage 存于当前会话；不以 UUID 代替登录身份，也不查询或关联订单、钱包、账号资料。后端只接收带有代理密钥的受信任请求。

对话存储为可选项：访客必须在客服窗口明确勾选“允许保存脱敏对话，供客服跟进与改进知识库”，才会把此轮问答写入客服工作台。未勾选仍可得到知识库答案，但该轮不会写入会话表。

新增三张表由 CustomerCommunicationSchemaInitializer 使用 CREATE TABLE IF NOT EXISTS 创建：
- t_support_conversation
- t_support_message
- t_support_learning_candidate

初始化只做增量建表，不执行 DROP、TRUNCATE 或 DELETE。生产环境配置 spring.sql.init.mode: never，因此采用应用启动后的显式幂等 schema initializer，避免依赖 SQL 自动初始化。

## 界面参考与设计原则

参考 [21st.dev](https://21st.dev/) 的社区组件目录与组件组合方式，重点吸收 AI Chats、Dashboards、Cards、Sidebars、Tables、Tags、Alerts、Modals 及 Empty States 的层级组织和微交互思路。实现仍遵循项目现有 Vue 3 + Ant Design Vue 技术栈，不直接移植 React/Tailwind 组件。主色沿用 LANLinkshopping 深海军蓝，辅以低饱和金色提示；动画只用于状态/光感反馈，并支持 prefers-reduced-motion。

## 脱敏与隐私

在写入会话记录和生成候选前，服务端会对常见邮箱、手机号、长数字串、身份/账户字段、姓名/地址提示字段以及凭据格式进行规则脱敏。该规则是纵深防御而不是完美个人信息识别；用户界面同时提示不要发送密码、验证码或银行卡信息。候选关键词也会再次经过脱敏与长度限制。

客户在公开客服窗口只能看到公开消息；内部备注 (sender_type=note) 不通过访客历史接口返回。管理端日志不记录原始问题、访客 token、IP 或代理密钥。请不要在调试日志中打印完整消息正文。

## 学习策略

1. 客户问题和人工客服回答保存在同一会话中，保存前执行脱敏。
2. 只有电商范围内的问题能生成候选；实时价格/库存、个人订单与钱包信息、密码/验证码、提示注入和内部配置等会被拦截。
3. 学习样本必须是同一会话里的客户问题与人工客服回答；自动机器人回复不能直接作为人工事实样本。
4. 候选初审后进入 pending。需要管理员再次核实事实、关键词边界、隐私和重复意图。
5. 管理员发布后才将其状态改为 published；SupportAnswerService 只会将 published 候选加入线上匹配，并保留原有固定知识库。
6. 这是一种人工审核的知识库扩展，不是自动训练模型。上线匹配仍有范围与安全拦截规则。

## 管理端 API

- GET /api/admin/customer-communications/overview
- GET /api/admin/customer-communications/conversations
- GET /api/admin/customer-communications/conversations/{id}
- POST /api/admin/customer-communications/conversations/{id}/messages
- PUT /api/admin/customer-communications/conversations/{id}/status
- PUT /api/admin/customer-communications/conversations/{id}/priority
- POST /api/admin/customer-communications/conversations/{id}/assign
- DELETE /api/admin/customer-communications/conversations/{id}/assign
- POST /api/admin/customer-communications/conversations/{id}/learn
- GET /api/admin/customer-communications/learning-candidates
- GET /api/admin/customer-communications/learning-candidates/{id}
- POST /api/admin/customer-communications/learning-candidates/{id}/review

公开代理功能：POST /api/support/ask，body action:"ask" 询问知识库，action:"history" 读取当前随机 UUID 会话中新增的公开消息。代理仍然强制同源来源校验、服务端密钥、输入长度、超时和限流。

## 发布前验收清单

- 管理员登录后确认三个新增表自动创建；非管理员调用所有 /admin/customer-communications/** API 应收到 403。
- 浏览器发起一条问题后，客服答复正确显示，管理端会话列表出现新会话；访客历史只显示该访客令牌对应的公开消息。
- 管理员回复后，在原浏览器窗口 12 秒内或重新打开客服窗口可见回复；内部备注始终不对客户可见。
- 状态、优先级、认领操作生效并留下审计日志。
- 创建候选需使用一条客户问题和一条人工回答；范围外问题、包含疑似凭据的问题和无效关键词必须被拒绝。
- 候选待审核时不影响线上回答；发布后才参与关键词匹配；驳回后不生效。
- 运行后端 mvn test 和前端 npm run build。生产部署命令若跳过测试，必须单独执行测试，不能将构建成功等同于测试通过。

## Docker 学习沙盒部署

容器源代码位于 support-learning-sandbox/，使用 Python 标准库提供无状态候选评估服务。容器以非 root 用户运行、构建阶段自动运行单元测试，请求限长并需要独立随机令牌；不挂载卷、不连接生产数据库、不运行动态代码或调用外部 API，访问日志不包含请求正文。

管理端 POST /api/admin/support-learning/preview 经由后端内部 HTTP 客户端转发到容器的 /v1/evaluate。调用包含问题、候选内容以及知识匹配器算出的范围/意图判定；容器只返回预检结果，不保存候选。生产部署必须设置 SUPPORT_SANDBOX_URL 与 SUPPORT_SANDBOX_TOKEN，并且两个服务使用相同的随机令牌。容器应仅通过 Railway 私有网络访问，不配置公网域名。SUPPORT_SANDBOX_MODE=container（默认）时，容器未配置或不可用即返回 503。只有显式设为 local 才会进入临时进程内降级模式；页面会醒目标明尚未通过 Docker 隔离验证，并禁用候选导出。

本仓库提供 support-learning-sandbox/docker-compose.yml 用于本地测试：只绑定 127.0.0.1、内部网络、只读根文件系统、丢弃 capabilities、禁止提权，并限制 CPU/内存/PID。

会话内容属于客户沟通资料。上线前应根据平台隐私政策确认存储期限、管理员访问审计、数据库备份与删除流程。当前模块不做自动模型训练、不自动把客户自由文本直接发布为知识、不提供任何个人订单/钱包查询。
