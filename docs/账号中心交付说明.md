# 账号中心交付说明

## 一、本次交付范围

依据《用户个人信息与系统设置页面设计与实现任务书》实现：

1. **个人信息管理**（前台 `/me`）
   - 基础信息只读/编辑双模式（姓名/昵称/性别/出生日期），日期范围限制（1900 ~ 满 14 周岁）
   - 头像上传（JPG/PNG/WebP、≤5MB、裁剪/缩放/旋转、进度条、失败重试）
   - 手机号/邮箱换绑（格式校验 + 验证码；演示环境验证码接口回显 devCode；换绑手机同步登录账号）
   - 联系方式脱敏展示（手机号中间 4 位、邮箱用户名前 3 位）
   - 个人简介 500 字 + 剩余字数统计 + 前后端双重脚本净化
   - 固定保存/取消按钮、未修改保存置灰、取消二次确认、编辑草稿 AES 加密刷新可恢复
2. **系统设置**（前台 `/me` → 系统设置）
   - 账户安全：密码修改（8-20 位含大小写字母/数字/特殊字符 + 实时强度条）、TOTP 两步验证（启用记录首次验证时间，**登录已接入二步校验**）
   - 通知偏好：邮件/推送/短信三开关 + 分类分组 + 一键全开全关（乐观更新失败回滚）
   - 界面个性化：亮色/暗色/跟随系统（含 antd 深色组件主题）、中英文、三档字号，实时生效并持久化
   - 隐私权限：个性化推荐/广告推送开关、第三方授权撤回（二次确认）、恢复默认设置（二次确认）
   - 全部设置操作成功/失败 3 秒浮层提示
3. **数据与安全**
   - IndexedDB 24h 缓存优先渲染 + 后台异步更新 + 增量提交
   - AES-GCM 加密草稿（localStorage）、敏感字段 AES-GCM 加密落库
   - 会话级 CSRF 令牌（拦截 + 前端自动重试）
   - 审计日志（改密/2FA/撤权/重置/清缓存），管理后台查询 + CSV 导出
4. **管理后台审计页**：`/admin/audit`（筛选 + 分页 + CSV 导出，仅 admin 角色）
