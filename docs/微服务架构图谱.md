# LANLinkshopping 微服务架构图谱（阶段 1 交付）

> 目标技术栈：Spring Boot 3.2.5 + Spring Cloud 2023.0.1 + Spring Cloud Alibaba 2023.0.1.2（Nacos 注册/配置中心）
> + OpenFeign 接口契约 + Spring Cloud Gateway 统一入口；前端 Vue3（Vue Router/Pinia）。
> 本文档定义服务拆分规范、职责边界、调用链路、接口契约与本地端口规划，作为阶段 2 全链路开发的实施基线。

---

## 一、服务拆分与职责边界（单一职责）

```
                              ┌──────────────────────────┐
                              │   Vue3 前端 (5173)        │
                              │  Vue Router + Pinia      │
                              └────────────┬─────────────┘
                                           │ /api/**（同源代理）
                                           ▼
                        ┌─────────────────────────────────────┐
                        │  lanlink-gateway (8300)             │
                        │  路由/鉴权过滤/跨域/限流（治理入口）   │
                        └───┬──────┬──────┬──────┬──────┬─────┘
        lb:// 负载均衡       │      │      │      │      │
   ┌───────────┬─────────────┼──────┼──────┼──────┼───────────────┐
   ▼           ▼             ▼      ▼      ▼      ▼               ▼
┌────────┐ ┌─────────┐ ┌────────┐┌─────┐┌──────┐┌────────┐  ┌──────────┐
│ auth   │ │merchant │ │product ││cart ││order ││payment │  │  Nacos   │
│ 8101   │ │ 8102    │ │ 8103   ││8104 ││ 8105 ││ 8106   │  │ 8848     │
│认证/用户│ │ 商户    │ │ 商品   ││购物车││ 订单 ││ 支付   │  │注册+配置  │
└────────┘ └─────────┘ └────────┘└─────┘└──────┘└────────┘  └──────────┘
```

| 服务 | 端口 | 职责 | 数据归属（阶段 2） | 消费的契约 |
|------|------|------|------------------|-----------|
| `lanlink-gateway` | 8300 | 统一入口：路由、鉴权过滤、跨域、限流、灰度预留 | 无状态 | — |
| `lanlink-auth-service` | 8101 | 登录鉴权、验证码、用户档案、RBAC 身份签发 | `t_user`/`t_role`/`t_user_profile` | — |
| `lanlink-merchant-service` | 8102 | 商户入驻申请、自动筛选、资质、审核状态流转 | `t_merchant`/`t_qualification` | `UserApi` |
| `lanlink-product-service` | 8103 | 行业/分类/商品、搜索、上架审核、首页数据 | `t_industry`/`t_category`/`t_product` | `MerchantApi` |
| `lanlink-cart-service` | 8104 | 购物车增删改查、勾选、价格快照校验 | `t_cart` | `ProductApi`、`UserApi` |
| `lanlink-order-service` | 8105 | 下单事务、库存扣减、订单/明细、积分抵现、状态机 | `t_order`/`t_order_item` | `ProductApi`、`CartApi`、`UserApi` |
| `lanlink-payment-service` | 8106 | 支付发起/回调/查单/退款（mock/微信/支付宝） | `t_pay_log`、支付流水 | `OrderApi` |

**拆分原则**：① 数据库按服务边界隔离（阶段 2 采用同实例分库 `lanlink_auth/lanlink_order/...`，禁止跨库 JOIN）；
② 服务间只允许通过 `lanlink-api` 中的 OpenFeign 契约调用，不允许直接读他服务的表；
③ 公共返回包装、异常、常量放 `lanlink-common`；④ 网关是唯一对外入口，服务端口不对前端暴露。

## 二、模块结构（cloud/ 多模块工程）

```
cloud/
├── pom.xml                    # 父 POM：Boot/Cloud/SCA 版本锁定 + 模块聚合
├── lanlink-common/            # 公共：R 统一响应、BusinessException、全局异常
├── lanlink-api/               # OpenFeign 接口契约（6 组）+ DTO（跨服务唯一契约源）
├── lanlink-gateway/           # Spring Cloud Gateway + 鉴权过滤器 + CORS
├── lanlink-auth-service/      # 认证/用户（8101）
├── lanlink-merchant-service/  # 商户（8102）
├── lanlink-product-service/   # 商品（8103）
├── lanlink-cart-service/      # 购物车（8104）
├── lanlink-order-service/     # 订单（8105）
├── lanlink-payment-service/   # 支付（8106）
└── logs/                      # 本地启动日志（gitignore）
```

## 三、接口契约（lanlink-api，OpenFeign）

统一响应包装（lanlink-common）：`R<T> { code, message, data }`，`code=200` 成功；
统一校验异常：`MethodArgumentNotValidException → code=400`；业务异常 `BusinessException → code=500/4xx`。

| 契约接口 | 提供方 | 方法与路径 | 说明 |
|---------|--------|-----------|------|
| `UserApi` | auth-service | `GET /users/{id}` | 用户基础信息（下单/购物车取档案） |
| `MerchantApi` | merchant-service | `GET /merchants/{id}`、`POST /merchants/apply` | 商户信息与入驻 |
| `ProductApi` | product-service | `GET /products/{id}` | 商品详情/价格（下单计价依据） |
| `CartApi` | cart-service | `GET /carts/{userId}`、`POST /carts/items` | 购物车读写 |
| `OrderApi` | order-service | `GET /orders/{orderNo}` | 订单信息（支付取金额） |
| `PaymentApi` | payment-service | `POST /payments` | 发起支付 |

**服务间调用链（核心业务）**：
```
下单： gateway → order-service
        ├── Feign ProductApi  校验商品状态与价格
        ├── Feign UserApi     取下单人档案/企业
        └── （阶段2）Feign CartApi 结算后清购物车
支付： gateway → payment-service
        ├── Feign OrderApi    取应付金额并锁定
        └── 回调成功 → Feign OrderApi 更新支付状态
```

## 四、网关路由表（lanlink-gateway）

| 前端路径 | 目标服务（lb://） | 说明 |
|---------|-----------------|------|
| `/api/auth/**`、`/api/users/**` | lanlink-auth-service | StripPrefix=/api |
| `/api/merchants/**` | lanlink-merchant-service | |
| `/api/products/**`、`/api/home/**` | lanlink-product-service | 首页数据归商品域 |
| `/api/carts/**` | lanlink-cart-service | |
| `/api/orders/**` | lanlink-order-service | |
| `/api/payments/**` | lanlink-payment-service | |

鉴权过滤（AuthGlobalFilter，阶段 1 占位实现）：公开前缀 `/api/auth/`、`/api/home/`、`/api/products/`(GET) 直接放行；
其余请求必须携带 `Authorization: Bearer <token>`，否则 401。阶段 2 升级为网关统一 JWT 校验 + 透传 `X-User-Id`。

## 五、本地环境与端口规划

| 组件 | 地址 | 部署方式 |
|------|------|---------|
| Nacos（注册+配置中心） | http://127.0.0.1:8848/nacos | Docker：`docker-compose.cloud.yml` |
| Gateway | http://127.0.0.1:8300/api | java -jar / mvn spring-boot:run |
| 6 个业务服务 | 8101–8106 | 同上（注册到 Nacos） |
| 前端 | http://localhost:5173 → /api 代理到 8300 | Vite（阶段 3 切换代理目标） |
| 旧单体（并存） | http://localhost:8080/api | 保留用于对照回归，阶段 2 后下线 |

环境变量：`NACOS_ADDR`（默认 `127.0.0.1:8848`）。版本栈：JDK 17（兼容 JDK 24 运行）、Maven 3.9、MySQL 8（阶段 2 分库）、Docker（Nacos）。

## 六、启动命令（阶段 1 一键脚本：cloud/start-dev.ps1）

```powershell
docker compose -f docker-compose.cloud.yml up -d        # Nacos
cd cloud; .\start-dev.ps1                               # 构建并启动 gateway + 6 服务
# 验证：
curl http://127.0.0.1:8848/nacos/v1/ns/service/list?pageNo=1&pageSize=20   # 7 个服务注册
curl -X POST http://127.0.0.1:8300/api/orders -H "Content-Type: application/json" `
     -H "Authorization: Bearer demo-token" -d '{"userId":2,"prodId":106,"quantity":1}'
# 返回订单号且金额来自 product-service（Feign 链路验证）
```

## 七、阶段边界（本阶段为骨架，业务逻辑在阶段 2 补全）

- ✅ 已交付：服务拆分骨架、版本栈锁定、Nacos 注册/配置接入、网关路由+鉴权过滤+跨域、OpenFeign 契约与真实跨服务调用示例（order→product、payment→order）、一键启动脚本、构建与运行验证。

- ⏭ 阶段 3：Vue 前端多级界面补全（代理切换到 8300）。
- ⏭ 阶段 4：单元/集成测试 + OpenAPI 文档 + 功能说明；最终阶段全量回归后清理冗余文件并输出变更记录。
