# LANLinkshopping 本地环境运行操作手册

> 适用范围：Windows 本机开发环境（MySQL 8 + Docker Desktop + JDK 17+ + Maven 3.9 + Node 18+）
> 本文档含：架构梳理 → 环境准备 → 一键启动 → 验证 → **配置修改项明细清单** → 常见问题。
> 按本文档操作即可在无额外指导的情况下复现本地运行环境。

---

## 一、架构梳理

### 1.1 总体架构

```
┌─────────────────────────── 浏览器 ───────────────────────────┐
│                     Vue 3 + Vite (5173)                       │
│  Pinia(store) · Vue Router(多级路由) · Ant Design Vue 4       │
│  axios 封装：baseURL=/api + withCredentials + CSRF 自动注入    │
└──────────────────────────┬────────────────────────────────────┘
                           │ /api 代理（vite.config.js）
                           ▼
┌────────────── Spring Boot 3.5.3 单体（8080, context=/api）──────┐
│ 拦截器链：AuthRateLimit → AuthInterceptor → PermInterceptor →   │
│          CsrfInterceptor（登录态 HttpSession + RBAC + CSRF）     │
│ ├─ controller：Auth/Home/Product/Merchant/Cart/Order/User/      │
│ │              Admin*/Payment/CreditTerm/Traffic/Marketing/...  │
│ ├─ service：Order(下单事务) Merchant(筛选) VerifyCode(验证码)    │
│ │           Payment(mock/微信/支付宝) Membership(积分)           │
│ │           Pricing(促销/会员折扣编排) Wallet/CreditTerm/...      │
│ ├─ mapper/entity：MyBatis-Plus 11 张业务表                      │
│ └─ config：WebConfig(跨域/静态映射) MybatisPlusConfig DataInit   │
└──────┬──────────────┬──────────────┬───────────────┬───────────┘
       │              │              │               │
       ▼              ▼              ▼               ▼
   MySQL 8.0      Mailpit        支付宝沙箱      support-learning
  (本机3306)   (Docker 1025/    (gateway-url)    sandbox 容器
   lanlink_     8081 收件箱)                      (127.0.0.1:18080)
   shopping
```

### 1.2 模块职责边界

| 模块 | 位置 | 职责 |
|------|------|------|
| 前端视图层 | `frontend/src/views` | 业务页面（商城/购物车/订单/会员/钱包/账期/管理后台等多级界面） |
| 前端状态层 | `frontend/src/store` | Pinia：user(登录态 ll_user)、cart(购物车) |
| 前端接口层 | `frontend/src/api` | `request.js` 统一实例（CSRF 拦截、401 跳转、错误提示）；`index.js` 按业务域封装 API |
| 前端路由 | `frontend/src/router` | 多级路由 + `meta.auth/admin/perms` 权限守卫 |
| 接入层 | `backend/config` | 拦截器链：限流→登录鉴权→RBAC 权限→CSRF |
| 业务层 | `backend/service` | 下单事务、商户筛选、验证码、支付、积分、定价编排 |
| 数据层 | `backend/mapper` + `entity` | MyBatis-Plus，逻辑删除 `deleted` |
| 会员/营销中台 | `backend/module/membership、promotion、activity` | 积分抵现、成长值、促销、活动 |
| 支付 | `backend/payment` | mock 支付（本地）、微信 APIv2、支付宝 RSA2 |
| 数据库脚本 | `backend/src/main/resources/sql` | `schema.sql`（11 张表+字典，幂等）、`account.sql` |

### 1.3 关键调用链路

- **登录**：`POST /api/auth/login`（phone+password）→ HttpSession 存 LOGIN_USER → 返回 identity/permissions
- **下单**：`POST /api/order/checkout` → 校验库存 → PricingFacade 定价（促销/会员折扣取优）→ 积分抵现（1000 分=1 元）→ 生成订单+明细快照 → 扣库存加销量 → 清购物车
- **支付**：`POST /api/payment/create` → mock 渠道 → `POST /api/payment/mock-confirm` → 订单支付成功 → 发事件（会员积分/成长值、活动参与）
- **验证码**：`POST /api/user/email-code` → VerifyCodeService → SMTP(Mailpit) 真实发送 + demo-mode 回显

### 1.4 接口传参规范

- 统一响应包装：`{ code, message, data }`，`code=200` 成功
- 认证：Session Cookie（JSESSIONID），axios `withCredentials: true`
- 写操作（`/user/**`、`/admin/marketing-email/**` 等）需 CSRF：先 `GET /api/user/csrf-token` 拿 token，请求头带 `X-CSRF-TOKEN`
- 前端 `request.js` 已自动完成 CSRF 注入与失效重试，业务代码无需关心

## 三、一键启动

### 3.1 首次准备（仅一次）

```powershell
# 1) 复制环境变量模板并填写（已包含 MySQL 密码、沙盒令牌等）
Copy-Item .env.example .env
#    → 编辑 .env：填入 SPRING_DATASOURCE_PASSWORD（MySQL root 密码）
#               与 SUPPORT_SANDBOX_TOKEN（≥40 字符随机串）

# 2) 前端依赖安装（首次）
cd frontend; npm install; cd ..
```

> 本仓库当前已存在 `.env`（本地值已填好，勿提交）与 `application-payment.yml`（已 gitignore）。

### 3.2 一键启动

```powershell
.\启动本地环境.bat
```

脚本自动完成：
1. `docker compose -f docker-compose.local.yml up -d`（Mailpit + 客服沙盒）
2. 以 dev profile 启动后端 jar（自动执行 schema.sql 建库建表）
3. 启动前端 Vite

启动后访问：

| 服务 | 地址 |
|------|------|
| 商城前端 | http://localhost:5173 |
| 后端接口 | http://localhost:8080/api |
| 邮件收件箱（Mailpit） | http://localhost:8081 |
| 客服学习沙盒健康检查 | http://127.0.0.1:18080/health |

演示账号（密码 `123456`）：

| 手机号 | 角色 |
|--------|------|
| 13800000000 | 平台运营 admin |
| 13900000001 | 采购方 buyer |
| 13700000002 | 商户 merchant |

### 3.3 手动分步启动（排查用）

```powershell
# ① 基础服务
docker compose -f docker-compose.local.yml up -d --build

# ② 后端（先打包，再带环境变量启动）
mvn -q -f backend/pom.xml package -DskipTests
Get-Content .env | Where-Object { $_ -match '=' -and $_ -notmatch '^\s*#' } | ForEach-Object {
  $kv = $_ -split '=',2; [Environment]::SetEnvironmentVariable($kv[0].Trim(), $kv[1].Trim(), 'Process')
}
java -jar backend\target\lanlink-shopping.jar --spring.profiles.active=dev

# ③ 前端
cd frontend; npm run dev
```

### 3.4 停止

```powershell
docker compose -f docker-compose.local.yml down     # 基础服务
# 后端/前端：关闭对应终端窗口
```

## 五、配置修改项明细清单

> 说明：`application-payment.yml`、`.env` 已加入 `.gitignore`，含本地凭据不入库。

### 5.1 后端配置

| 配置项路径 | 原配置值 | 本地配置值 | 修改说明 |
|-----------|---------|-----------|---------|
| `backend/src/main/resources/application-dev.yml` → `server.servlet.session.cookie.secure` | `true`（继承 application.yml） | `false` | 原为 Vercel/Railway 跨站 HTTPS 策略；本地 HTTP 下 secure=true 会导致浏览器丢弃登录 Session |
| 同上 → `server.servlet.session.cookie.same-site` | `none` | `lax` | 同上，同源本地开发用 lax 即可，且避免浏览器第三方 Cookie 限制 |
| 同上 → `spring.datasource.url` | （env 注入） | `jdbc:mysql://localhost:3306/lanlink_shopping?...&createDatabaseIfNotExist=true` | 指向本机 MySQL，自动建库 |
| 同上 → `spring.datasource.username` | （env 注入） | `root` | 本机 MySQL 账号 |
| 同上 → `spring.datasource.password` | （env 注入，仓库不存） | `.env` 中 `SPRING_DATASOURCE_PASSWORD` | 本地 MySQL 口令，走环境变量 |
| 同上 → `spring.mail.host` | `${MAIL_HOST:}`（空） | `localhost`（env 可覆盖） | 本地 Mailpit SMTP |
| 同上 → `spring.mail.port` | `465` | `1025` | Mailpit SMTP 端口 |
| 同上 → `spring.mail.username/password` | （空） | `lanlink@local.dev` / `lanlink-local` | Mailpit 免认证收信，任意非空即可满足 smtpConfigured 判定 |
| 同上 → `mail.smtp.auth` | `true` | `false` | Mailpit 无需认证 |
| 同上 → `mail.smtp.ssl.enable` | `true` | `false` | Mailpit 本地明文 SMTP |
| 同上 → `LANLINK_PUBLIC_API_URL` | `https://lanlinkshopping-production.up.railway.app/api`（代码默认） | `http://localhost:8080/api` | 营销邮件退订链接基址本地化 |
| 同上 → `SUPPORT_SANDBOX_URL` | （空） | `http://127.0.0.1:18080` | 客服学习沙盒容器地址 |
| 同上 → `SUPPORT_SANDBOX_TOKEN` | （空） | `.env` 中配置（≥40 字符） | 沙盒访问令牌，与容器共享 |
| 同上 → `SUPPORT_SANDBOX_MODE` | `container` | `container` | 容器隔离评估模式 |
| `backend/src/main/resources/application-payment.yml`（新建，gitignored）→ `lanlink.payment.mock` | `false`（prod 默认） | `true` | 本地 mock 支付，不触达真实渠道即可跑通发起/回调/查单/退款 |
| 同上 → `lanlink.payment.notify-base-url` | 生产域名示例 | `http://localhost:8080/api` | 支付回调/跳转基址本地化 |
| 同上 → `lanlink.payment.alipay.gateway-url` | `https://openapi.alipay.com/gateway.do` | `https://openapi-sandbox.dl.alipaydev.com/gateway.do` | 指向支付宝沙箱网关（密钥留占位符） |
| 同上 → `lanlink.payment.wechat.*` / `alipay.app-id/private-key` | 生产密钥示例 | 空占位符 | 本地不联调真实渠道，密钥不入库 |

## 六、常见问题

1. **登录后接口仍 401 / Session 丢失**
   确认 `application-dev.yml` 中 session cookie 为 `secure: false`、`same-site: lax`，并使用 `--spring.profiles.active=dev` 启动。

2. **后端启动报 MySQL 连接失败**
   检查 MYSQL8.0 服务已启动；`.env` 中 `SPRING_DATASOURCE_PASSWORD` 与本机 root 密码一致。

3. **`repackage` 无法 rename jar**
   旧后端进程仍在运行占用 jar。先 `Stop-Process -Name java`（或关闭后端窗口）再 `mvn package`。

4. **Docker 拉取镜像超时**
   网络受限导致 Docker Hub 访问失败，稍后重试；Mailpit/沙盒镜像成功拉取后会缓存本地。

5. **Mailpit 收不到邮件**
   确认容器端口映射为 `1025:1025` 与 `8081:8025`（新版 Mailpit 的 HTTP 端口是 8025 不是 8080）。

6. **客服沙盒容器反复重启**
   `SUPPORT_SANDBOX_TOKEN` 必须 ≥40 字符：`powershell -c "[guid]::NewGuid().ToString('N')+[guid]::NewGuid().ToString('N')"`。

7. **PowerShell 中文提交后变 `???`**
   curl 提交 JSON 需 UTF-8 无 BOM：`[IO.File]::WriteAllText(path, json, (New-Object System.Text.UTF8Encoding $false))`；或直接用前端页面操作（已正常）。

8. **积分不足 1 元不能抵扣**
   规则设计如此：1000 积分 = 1 元，最小抵扣 1 元，不足 1000 积分的零头不参与抵扣。
