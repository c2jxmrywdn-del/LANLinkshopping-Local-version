# 账号中心接口文档

> 对应页面：前台「个人中心」/me（个人信息 + 系统设置）、管理后台「审计日志」/admin/audit。
> 所有接口统一响应封装：`{"code":200,"message":"操作成功","data":...}`，`code=200` 表示成功，其余为失败（`message` 为错误说明）。

## 通用约定

| 项目 | 说明 |
|---|---|
| Base URL | 开发环境 `http://localhost:8080/api`（前端经 Vite 代理 `/api`） |
| 登录态 | Session（Cookie），`/user/**` 与 `/admin/**` 必须在登录后访问 |
| CSRF | **所有非 GET 且路径以 `/user` 开头的请求**必须携带 `X-CSRF-TOKEN` 头，值与 `GET /user/csrf-token` 返回的一致；令牌随会话存储，失效时 403 + message 含 "CSRF"，前端自动换新重放一次 |
| 权限 | `/admin/**` 仅 `admin` 角色（role_id=3）可访问 |
| 鉴权失败 | `{"code":401,"message":"请先登录"}`，前端自动跳转登录页 |

## 认证（/auth）

### POST /auth/login
- 入参：`{"phone":"13900000001","password":"123456"}`
- 成功（未启用两步验证）：`data` = 用户视图 `{userId, phone, nickname, roleId, roleCode, roleName, entId}`
- 成功（已启用两步验证）：**不建立会话**，返回 `data = {require2fa:true, loginTicket:"一次性票据", hint:"139****0001"}`
  - 前端随后调用 `POST /auth/login/2fa` 完成登录

### POST /auth/login/2fa
- 入参：`{"loginTicket":"...","code":"123456"}`（票据 5 分钟有效、单次使用）
- 校验动态码成功后建立会话，返回同 `/auth/login` 的用户视图
- 失败：`动态验证码错误` / `登录状态已过期，请重新登录`

### POST /auth/logout · GET /auth/me
- logout：销毁会话，返回空 data
- me：返回当前用户视图（未登录返回 401 但前端静默处理）

## 个人信息（/user）

### GET /user/csrf-token
- 返回 `data={token}`：当前会话的 CSRF 令牌（未生成则先生成，重复调用幂等）

### GET /user/profile
- 返回合并视图（基础字段来自 t_user，资料字段来自 t_user_profile，敏感字段已解密为明文）：
```json
{ "userId":2, "realName":null, "nickname":"重庆建工采购", "gender":"", "birthday":"",
  "avatar":"", "bio":"", "phone":"13900000001", "email":null }
```
- `phone` 在资料表未绑定时回退为登录手机号

### PUT /user/profile
- 入参（部分更新，仅提交改动的字段）：`{"realName":"","nickname":"","gender":"male|female|secret","birthday":"2000-01-01","bio":"..."}`
- `nickname` 写 t_user，其余写 t_user_profile；`bio` 服务端净化（剔除 script/style 与标签，最长 500 字）
- 返回更新后的完整 profile

### POST /user/avatar
- multipart 表单，字段名 `file`；仅支持 JPG/PNG/WebP，≤5MB
- 返回 `data={url:"/api/uploads/avatars/{userId}_{ts}.png"}`，图片经 `/api/uploads/**` 静态访问

## 联系方式换绑（演示环境验证码由接口直接回显）

| 接口 | 成功 data | 说明 |
|---|---|---|
| POST /user/phone-code `{phone}` | `{devCode:"123456"}` | 触发校验：手机号格式；60s 冷却、5min 过期 |
| POST /user/phone-bind `{phone,code}` | 完整 profile | 校验验证码 → 新号唯一性检查 → 同步 t_user.phone（登录账号随之切换） |
| POST /user/email-code `{email}` | `{devCode:"123456"}` | 触发校验：邮箱格式 |
| POST /user/email-bind `{email,code}` | 完整 profile | 校验验证码 → 写 t_user_profile.email |

## 账户安全

### POST /user/password
- 入参：`{"oldPassword":"...","newPassword":"..."}`
- 规则：原密码正确；新密码 8-20 位，**必须包含 大写字母、小写字母、数字、特殊字符**；不得与原密码相同
- 成功记录审计 `CHANGE_PASSWORD`

### GET /user/security
- 返回 `data={totpEnabled:true, firstVerifyTime:"2026-10-01 21:04:23"}`（未启用时 firstVerifyTime=null）

### POST /user/2fa/setup
- 返回 `data={secret:"32位Base32", otpauthUrl:"otpauth://totp/LANLink:手机号?secret=...&issuer=LANLinkshopping"}`（草稿态：密钥密文入库、未启用；重复 setup 重置密钥）

### POST /user/2fa/enable `{code}`
- RFC 6238（HmacSHA1 / 30s / 6 位，±1 窗口容忍时钟偏差）；成功后 `enabled=1` 并记录首次验证时间；审计 `ENABLE_2FA`

### POST /user/2fa/disable `{code}`
- 校验当前动态码后删除密钥并关闭；审计 `DISABLE_2FA`

## 系统设置

### GET /user/settings
- 返回完整设置（无记录时返回平台默认值）：
```json
{ "notify":{"email":true,"push":true,"sms":false,"groups":{"order":true,"promotion":false,"system":true}},
  "appearance":{"theme":"system","language":"zh-CN","fontSize":"standard"},
  "privacy":{"recommend":true,"ads":false} }
```

### PUT /user/settings
- 入参：部分 patch（嵌套字段深合并，如 `{"notify":{"sms":true}}` 只改提示短信）
- 返回合并后的完整设置

### POST /user/settings/reset
- 恢复平台默认值（仅系统设置，不影响个人信息）；审计 `SETTINGS_RESET`

## 第三方授权

### GET /user/third-auth
- 返回 `data=[{id,userId,appName,appIcon,scopes,authTime,createTime}]`（仅本人授权记录）

### DELETE /user/third-auth/{id}
- 撤回授权：校验归属（他人记录 500"授权记录不存在"）；审计 `REVOKE_THIRD_AUTH`

## 审计日志

### POST /user/audit
- 入参：`{"action":"CACHE_CLEAR","detail":"清除本地缓存"}`；客户端事件上报（如清空缓存），服务端记录时间、IP、User-Agent

### GET /admin/audit/page
- 参数：`page`(默认1)、`size`(默认10)、`userId?`、`action?`、`beginDate?(yyyy-MM-dd)`、`endDate?`
- 返回 `data={records:[...], total, page, size}`（按 id 倒序）

### GET /admin/audit/export
- 参数同 page；返回 `text/csv`（UTF-8 带 BOM，Excel 直接打开不乱码），文件名 `audit_log_时间戳.csv`

## 关键审计动作对照

| 动作编码 | 触发场景 |
|---|---|
| CHANGE_PASSWORD | 修改密码 |
| ENABLE_2FA / DISABLE_2FA | 两步验证启用/关闭 |
| REVOKE_THIRD_AUTH | 撤回第三方授权 |
| SETTINGS_RESET | 恢复默认设置 |
| CACHE_CLEAR | 前端清空本地缓存（客户端上报） |
