# 前端数据安全与字段映射规范

> 对应需求 1-5：数据库存储结构信息（表名/字段名/字段类型/SQL）严禁出现在任何前端可访问位置。
> 所有转换逻辑仅在后端完成；前端仅接触业务语义字段。

## 1. 分层模型（数据映射层）

```
[MySQL 存储层]  t_xxx 表 / snake_case 列 / deleted 逻辑列 / *_json 快照列
      ↓  MyBatis-Plus 映射（仅后端可见）
[实体层]  Entity 类（camelCase 属性 ↔ 列映射，@TableName 只存在于后端字节码）
      ↓  序列化边界（本规范管控点）：@JsonIgnore / @JsonProperty(WRITE_ONLY) / VO
[接口层]  业务语义 JSON（前端唯一可见面）
      ↓
[前端]  业务字段（prodId/orderNo/payType...），禁止出现 t_ 前缀、snake_case 列名、SQL 片段
```

**规则：实体类的 `@TableName`/列名注解永远不会被 Jackson 序列化输出**（注解不进 JSON）；
泄露风险仅来自「字段值」与「字段名」两类，管控点如下。

## 3. 错误信息统一脱敏（需求 3）

- [GlobalExceptionHandler](../backend/src/main/java/com/lanlink/shopping/common/GlobalExceptionHandler.java)：
  - `DataAccessException` → 前端只收到「数据服务暂时不可用，请稍后重试」，SQL/表名/约束名仅落 `[db-error]` 服务端日志
  - `BusinessException` → 业务文案（开发时禁止拼接 `e.getMessage()` 的异常原文）
  - 校验失败 → Bean Validation 注解中的业务文案（如"收货人过长"）
- **禁止模式**（代码评审红线）：
  ```java
  // ❌ 异常原文拼接（可能含 SQL 片段/列名）
  throw new BusinessException("下单失败: " + e.getMessage());
  // ✅ 固定文案 + 服务端日志
  log.error("[biz-error] 下单失败", e);
  throw new BusinessException("下单失败，请稍后重试");
  ```

## 4. 接口契约：业务语义别名（需求 2/5）

前端已使用的字段标识均为**业务语义命名**（非数据库列名直出）：

| 业务字段（前端可见） | 语义 | 说明 |
| --- | --- | --- |
| prodId / title / price / stock | 商品标识/名称/价格/库存 | 业务词 |
| orderNo / payType / payStatus / refundStatus | 订单号/支付方式/支付状态/退款状态 | 业务状态机语义 |
| waybillNo / logisticsNo / freight | 运单号/快递单号/运费 | 业务词 |
| receiver / phone / address | 收货信息 | 业务词 |
| idempotentKey / usePoints | 幂等键/使用积分 | 防篡改契约字段 |

**新增接口字段时**：
1. 后端 DTO/VO 使用业务命名（禁止直接暴露 Mapper 查询别名、SQL 别名）
2. 存储层特有字段（快照/标记/密钥）不进 DTO，或 `@JsonIgnore`
3. 前后端契约同步至 [数据校验规则契约.md](数据校验规则契约.md)（校验规则）与本文档（字段映射）

## 5. 专项安全检查清单（需求 4，发布前执行）

| # | 检查项 | 方法 | 通过标准 |
| --- | --- | --- | --- |
| 1 | 前端源码无表名/SQL | `rg "t_[a-z_]+\|SELECT \|INSERT \|UPDATE .* SET" frontend/src` | 0 命中（业务词除外） |
| 2 | 前端源码无 snake_case 列名 | `rg "prod_id\|user_id\|order_no\|pay_status\|ent_id\|mer_id" frontend/src` | 0 命中 |
| 3 | 接口响应无存储层字段 | 抓包/`DataExposureSafetyTest` | 无 deleted/*Json 后缀字段 |
| 4 | 错误响应无 SQL 详情 | 触发 DB 异常（断库）观察响应 | 统一脱敏文案 |
| 5 | 控制台日志无敏感输出 | 前端 `rg "console\.(log)"` | 仅保留必要的 warn/error |
| 6 | 密钥不回显 | 调用服务商管理接口看响应 | apiKey 字段不存在于响应 |

## 6. 运行结果（2026-10-16 本次审计）
