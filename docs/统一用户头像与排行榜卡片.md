# 统一用户头像与排行榜卡片

## 现有前端结构

当前主应用使用 Vue 3 + Vite + Ant Design Vue，入口是 `frontend/src/main.js`，页面组件集中在 `frontend/src/components`，全局品牌样式位于 `frontend/src/styles/theme.css`。仓库目前不是 React + TypeScript + Tailwind 项目：没有 React、`tsconfig.json`、Tailwind 配置或 `components.json`。所以不能把 React TSX 直接导入当前 Vue 页面，也不建议为了一个头像组件迁移整个平台。

这次沿用当前技术栈，在 `frontend/src/components/ui` 建立共享 UI primitives 目录，并新增 Vue 版头像与排行榜卡片。独立 `ui` 子目录可以让低耦合组件跨页面复用、统一维护尺寸和状态样式，并与业务视图隔离。如果以后建立 React/shadcn 子应用，组件通常应位于该应用的 `src/components/ui`；其 `components.json` 中的 `ui` alias 应指向 `@/components/ui`，而不是依赖当前 Vue 应用的相对路径。

## 头像角色规则

1. 用户主动上传的头像优先显示。
2. 没有上传头像时，普通用户使用默认商务头像。
3. 个人资料的性别为 female 时使用同风格女性头像。
4. 平台管理员使用更沉稳的管理者头像；管理员角色优先于性别默认头像。
5. 外链头像加载失败时自动回到本地生成的头像资源。素材保存在 `frontend/src/assets/avatars/user-avatar-sprite.webp`，避免把系统默认头像依赖在第三方图片站。

## 在新页面中复用

```vue
<UserAvatar
  :src="profile.avatar"
  :name="profile.nickname"
  :gender="profile.gender"
  :role="isAdmin ? 'admin' : 'user'"
  :size="56"
/>
```

排行榜组件 `first-place-leaderboard.vue` 提供金额、排名、分数、色调和头像等 props，供真实排行榜页面直接复用。此提交不会假造线上排行数据；接入商户/活动排行时，再用实际服务端数据渲染。

## 将来若创建独立 React + TypeScript + Tailwind + shadcn/ui 应用

推荐建立独立子应用，而不是把现有 Vue SPA 改造成混合 Vue/React 应用。在目标 React 应用目录的上一级执行：

```bash
npm create vite@latest frontend-react -- --template react-ts
cd frontend-react
npm install
npm install tailwindcss @tailwindcss/vite lucide-react clsx tailwind-merge
npx shadcn@latest init
```

初始化时配置 `@/*` import alias、Tailwind CSS 入口和 `components.json`。shadcn 组件默认可放在 `src/components/ui`；`components.json` 的 `ui` alias 应映射到 `@/components/ui`，utils alias 应映射到 `@/lib/utils`。React 版组件使用的 `cn()` 可由 `clsx` 与 `tailwind-merge` 提供；根据 React 子应用的目录结构配置 Vite 和 TypeScript 的 alias。

参考 shadcn 官方说明：
- https://ui.shadcn.com/docs/installation/vite
- https://ui.shadcn.com/docs/components-json
- https://ui.shadcn.com/docs/tailwind-v4

以上是将来独立 React 子应用的初始化指引；本次改动不会给现有 Vue SPA 加装第二套前端运行时。
