# 前端 UI/UX 全面优化 · 设计调整说明

> 版本：v2.0 · 2026-10-14
> 范围：`frontend/` 全站（Vue 3 + Vite + Ant Design Vue）
> 标杆参考：21st.dev（克制、精致、以内容与留白为主的现代电商设计语言）

---

## 一、优化总览

本轮优化在既有品牌体系（双环 LOGO 色板、浅天蓝交互色）之上，围绕四个目标展开：

1. **设计系统化**：将散落在各页面的硬编码数值收敛为统一的设计令牌（间距 / 圆角 / 阴影 / 字号 / 缓动），保证全站视觉刻度一致。
2. **深色模式闭环**：此前深色主题仅切换 AntD 组件，自定义样式仍为浅色，观感割裂；现已通过 `[data-theme='dark']` 令牌翻转实现全局一致的深色界面。
3. **全链路交互反馈**：加载（骨架屏）、点击（波纹/回弹）、状态变化（徽标弹跳）、滚动（导航联动/返回顶部）均有自然、克制的动效反馈。
4. **响应式与可达性**：所有核心页面适配手机/平板/桌面，键盘焦点环、`prefers-reduced-motion` 降级、空态与错误态容错完整。

## 二、设计令牌体系（Design Tokens v2）

所有令牌定义于 `frontend/src/styles/theme.css`，页面样式优先读取令牌而非硬编码。

### 2.1 间距刻度（8pt 网格）

| 令牌 | 值 | 典型用途 |
|---|---|---|
| `--ll-space-1` | 4px | 图标与文字间距 |
| `--ll-space-2` | 8px | 紧凑元素组内间距 |
| `--ll-space-3` | 12px | 卡片内小间距 |
| `--ll-space-4` | 16px | 栅格间距 / 卡片内边距 |
| `--ll-space-6` | 24px | 区块间距 |
| `--ll-space-8` | 32px | 大区块分隔 |
| `--ll-space-10/12` | 40/48px | 页面级留白 |

### 2.2 圆角刻度

| 令牌 | 值 | 典型用途 |
|---|---|---|
| `--ll-radius-sm` | 8px | 缩略图、小控件 |
| `--ll-radius-md` | 10px | 地址卡、支付方式卡 |
| `--ll-radius-lg` | 14px | 工具栏、促销条 |
| `--ll-radius-xl` | 18px | 卡片、弹窗 |
| `--ll-radius-2xl` | 24px | 商品卡 |
| `--ll-radius-full` | 999px | 胶囊按钮、返回顶部 |

### 2.3 阴影刻度

`--ll-shadow-xs / sm / md / lg / xl` 五级，浅色模式使用蓝灰调（`rgba(19,35,58,*)`）保持通透，深色模式自动切换为更深的纯黑阴影。

### 2.4 字号刻度

`--ll-text-xs(12) / sm(13) / base(14) / md(16) / lg(18) / xl(22) / 2xl(28)`，配合三档行高令牌（tight 1.25 / normal 1.6 / relaxed 1.9）。

### 2.5 边框与表面

新增 `--ll-border`、`--ll-border-strong`、`--ll-card`、`--ll-card-soft`，深色模式自动翻转；组件以 `var(--ll-border, #e5e7eb)` 兜底方式引用，向后兼容。

### 2.6 缓动曲线

| 令牌 | 值 | 用途 |
|---|---|---|
| `--ll-ease-out` | `cubic-bezier(0.22, 1, 0.36, 1)` | 进场/位移类动效（21st.dev 式减速曲线） |
| `--ll-ease-spring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 徽标弹跳等强调动效 |

## 三、深色模式

- 用户在「账户设置 → 外观」切换深色/跟随系统后，`settings` store 在 `<html>` 写入 `data-theme="dark"`。
- AntD 组件由 `App.vue` 的 `darkAlgorithm` 接管；自定义样式由 `[data-theme='dark']` 令牌覆盖接管（页面底色、卡片表面、文字、边框、阴影、价格红）。
- 刻意保留浅色的"画布"区块：商品详情页纸感编辑区块、关于我们品牌页——它们作为深色底上的内容层，属于设计意图而非遗漏。
- `App.vue` 增加 `colorBgLayout: 'transparent'`，让 `--ll-page` 成为唯一页面底色，避免 AntD 布局底色与令牌底色在两种主题下互相打架。

## 四、页面级优化明细

### 4.1 全局框架（MainLayout）

| 项 | 调整 |
|---|---|
| 顶栏滚动状态 | 下滑 >8px 后顶栏追加投影（`.is-scrolled`），强化悬浮层级感 |
| 购物车徽标 | 数量增加时红色计数弹跳（spring 曲线），提供"已加入"的视觉确认 |
| 返回顶部 | 新增 `BackToTop.vue`：滚动超过 1.5 屏浮现，点击平滑回顶，尊重减少动效偏好 |
| 页脚 | 颜色全部令牌化，深色模式下字色/分隔线自动适配 |

### 4.2 首页（Home）

- **骨架屏加载态**：行业卡与热销商品在请求期间展示与真实卡片同尺寸/同比例的 shimmer 骨架，消除加载完成时的布局跳动（此前为空白渐入）。
- 行业卡标题色由固定海军蓝改为 `--ll-ink` 令牌，深色模式可读。
- 承诺条（DISCOVER→TRANSACT→GROW）深色模式表面翻转。

### 4.3 商城（Mall）

- **骨架屏替代遮罩式 Spin**：加载与翻页均展示 8 张骨架商品卡，观感更轻盈。
- **工具栏容器化 + 粘性**：搜索/筛选控件收入毛玻璃容器，桌面端吸顶（跟随 64px 头部），长列表浏览中随时可调整筛选；移动端贴合双行头部。
- 新增结果计数（"共 N 件商品"）。
- **空状态增强**：图标 + 文案 + 「清空筛选条件」一键重置（新增 `resetFilters`）。
- 分页器仅在 `total > pageSize` 时显示，减少视觉噪音。

### 4.4 商品详情（ProductDetail）

- **图集切换过渡**：缩略图切换时主图淡入 + 轻微缩放（380ms ease-out）。
- **详情导航滚动联动**：`IntersectionObserver` 追踪"商品介绍 / 规格参数 / 服务说明"可见性，吸顶导航高亮当前区块；点击平滑滚动（`scroll-margin-top` 适配吸顶高度）。
- 吸顶导航 `top` 从 0 调整为 64px，避免被主头部遮挡。

### 4.5 购物车（Cart）

- 商品列新增 **56px 缩略图**（读取后端 `CartItemVO.coverUrl`），无图时展示首字占位；悬停图片轻微缩放。
- 商品标题悬停变主色，行悬停背景过渡更顺滑。
- 合计金额、分隔线颜色令牌化（深色模式自动适配）。

### 4.6 结算页（Checkout）

- 地址卡悬停轻微上浮，选中态保持品牌蓝描边 + 浅蓝底。
- 卡片圆角、实付金额颜色令牌化。

### 4.7 登录/注册（Login）

- 页面背景加入品牌双色氛围光斑（天蓝 + 琥珀径向渐变）。
- 卡片升级为悬浮式（大圆角 + 大阴影 + 边框），进入时上浮淡入。
- 密码强度条增加颜色过渡。

### 4.8 我的订单（MyOrders）

- 支付渠道选项卡悬停上浮、按压回缩，边框/圆角令牌化。

## 五、动效与微交互规范（motion.css）

| 场景 | 规范 |
|---|---|
| 页面切换 | out-in 模式：离开 160ms 上浮淡出，进入 260ms 上浮淡入（`--ll-ease-out`） |
| 按钮 | 悬停上浮 1px + 投影，按压回缩 0.98；全站 `.ant-btn` 点击波纹（深浅表面自适应色） |
| 滚动进场 | `[data-reveal]` 元素进入视口时 550ms 上浮/侧滑/缩放进场的 |
| 骨架屏 | 1.35s shimmer 循环，颜色读取表面令牌（深色模式自动适配） |
| 徽标弹跳 | 0.5s spring 曲线，数量增加时触发 |
| 弹窗/模态 | 遮罩 2px 模糊，内容大圆角 + xl 阴影 |
| 表单焦点 | 柔和 3px 主色光环；错误抖动 `.ll-shake` |
| 数字变化 | `.ll-num-pop` 340ms 缩放强调 |

**统一时长纪律**：微交互 0.15–0.3s，区块进场 0.3–0.55s；除徽标弹跳外全部使用 ease-out 类曲线，避免弹跳过度。

## 六、可达性与容错

- **键盘焦点环**：全局 `:focus-visible` 统一 3px 品牌蓝光环（深色模式切换为亮青），鼠标操作不显示。
- **减少动效**：所有动画均在 `prefers-reduced-motion: reduce` 下降级为瞬时/静态。
- **空状态**：商城（可重置筛选）、购物车（去逛逛）、订单（去下单）均提供行动按钮。
- **加载失败**：个人中心提供重试；商品详情加载失败有 message 提示与空态。
- **选区颜色**：`::selection` 使用品牌蓝半透明底，深色模式自动调整。
- **滚动条**：WebKit 细滚动条 + Firefox `scrollbar-width: thin`，悬停加深。

## 七、响应式断点

| 断点 | 策略 |
|---|---|
| ≥1200px | 内容最大宽 1200px 居中，商品 4 列 |
| 992–1199px | 商品 3 列，头部间距收紧 |
| 768–991px | 商品 2 列，结算页转单列 |
| ≤767px | 头部双行（品牌行 + 可横滑导航行）、工具栏纵向全宽、购物车缩略图缩小、商品详情底部购买栏（safe-area 适配） |

商品卡在 ≤600px 切换为自适应高度，避免固定 3:4 在窄屏裁切内容。
